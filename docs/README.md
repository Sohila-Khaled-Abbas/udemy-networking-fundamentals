## Personal lab-notes workflow

For each exercise, capture the question, prediction, exact command, observed output, conclusion, and next experiment. Start from the reusable [lab-notes template](lab-notes-template.md).

## Documentation standards

A good runbook should state prerequisites, working directory, exact commands, expected output, interpretation, cleanup/stop instructions, troubleshooting, and safety boundaries. Prefer commands that work from a fresh clone; avoid machine-specific absolute paths.
